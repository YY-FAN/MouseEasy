# MouseEasy 1.1 功能与验收

## 功能检查

| 功能 | 如何检查 | 预期表现 |
| --- | --- | --- |
| 滚轮与触控板 | 在「所有鼠标」中开启纵向反转，用鼠标和触控板分别滚动同一页 | 鼠标方向改变，触控板沿用系统设置。 |
| iPhone 镜像 | 在镜像专用模块开启反转，分别试用 1 倍与 5 倍速度，连续拨动和间歇拨动滚轮 | 纵向方向按设置反转，所选倍速对镜像生效。 |
| 修饰键横向滚动 | 在一级页面选 Option 横向滚动，再检查下方修饰键行为，并在镜像中按住 Option 滚动 | 两处显示同一绑定，镜像中的横向滚动也使用专用倍速。 |
| 新鼠标继承配置 | 在「所有鼠标」中设置滚动方向，再换一只没有侧键的鼠标 | 新鼠标继承通用滚动设置，对应按钮实际触发时才执行绑定。 |
| 应用单独设置 | 连续添加两个应用，再选择其中一个修改方向 | 两个应用都保留在列表中，各自使用其专属规则。 |
| 应用例外 | 把已有单独规则的应用加入例外，再移出例外 | 例外期间暂停全部 MouseEasy 输入设置，移出后恢复原有规则。 |
| 移除与取消 | 点击应用行右侧的移除按钮，核对确认框中的应用名，再分别测试确认与取消 | 操作作用于该行的应用，在弹窗中取消修改可撤销本次编辑。 |
| 镜像设置范围 | 在「所有应用」、iPhone 镜像和其他应用之间切换 | 镜像专用模块在前两种范围中显示。 |
| 侧键操作 | 两个侧键均未绑定时，在「按钮」中套用「窗口切换」 | 短按 #3 切换当前应用窗口，短按 #4 切换应用，点击名称可更换动作。 |
| 指针与缩放 | 调整指针速度或加速度，在支持缩放的应用中试用 Ctrl＋滚轮 | 指针按设置移动，滚轮配合 Ctrl 执行指定动作，设置说明在应用内展开。 |
| 设置与退出 | 隐藏 Dock 和菜单栏图标后关闭窗口，从「应用程序」再次打开 | 设置窗口回到前台，「通用 → 启动与显示」可退出。 |
| 语言与打赏 | 切换中英文并点击「打赏」 | 弹窗提供 PayPal 主页和账号复制入口，复制后显示反馈。 |
| 安装与升级 | 使用 DMG 内的 PKG 升级已有安装 | 安装到「应用程序」的固定位置并更新启动器登记，现有配置沿用。 |
