# MouseEasy 1.0 功能与验收

## 验收范围

| 功能 | 如何检查 | 预期表现 |
| --- | --- | --- |
| 滚轮与触控板 | 在「所有鼠标」中开启纵向反转，用鼠标和触控板分别滚动同一页 | 鼠标方向改变，触控板继续沿用系统设置。 |
| 新鼠标继承配置 | 在「所有鼠标」中设置滚动方向，再换一只没有侧键的鼠标 | 新鼠标继承通用滚动设置。只有实际按下对应侧键才会触发绑定。 |
| 应用单独设置 | 选择一个应用，为它设置不同的滚动方向，再切换应用 | 选中的应用使用专属设置，其他应用继续使用通用设置。 |
| 侧键操作 | 两个侧键均未绑定时，在「按钮」中套用「窗口切换」 | 短按 #3 切换当前应用的窗口，短按 #4 切换应用。点击操作名称可直接更换动作。 |
| 指针与缩放 | 调整指针速度或加速度，在支持缩放的应用中试用 Ctrl＋滚轮 | 指针按设置移动，滚轮配合 Ctrl 执行指定的缩放动作。 |
| 设置与退出 | 隐藏 Dock 和菜单栏图标后关闭设置窗口，从「应用程序」再次打开 MouseEasy | 设置窗口回到前台，可从「通用 → 启动与显示」退出。 |

## 自动检查与实机表现

配置与滚动测试使用模拟输入，覆盖通用规则继承、应用覆盖、滚动方向、位移和手势阶段。复现命令见[开发与构建](development.md#验证)。

iPhone 镜像可单独设置滚动速度和收尾时间。实机上轻拨一格可以启动滚动，但慢拨仍可能出现停顿。音乐 App 的歌单上滚也可能触发返回。比较手感时，在同一列表中段、同一位置分别使用触控板和滚轮，上下都留出滚动空间。
