下载 MouseEasy

适用于搭载 Apple 芯片的 Mac，包括 M1 及后续 M 系列的 MacBook、iMac、Mac mini、Mac Studio 和 Mac Pro。打开苹果菜单中的「关于本机」，可以查看芯片和 macOS 版本。

系统要求为 macOS 12 或更高版本。当前安装包仅含 arm64，Intel Mac 无法运行。已在 macOS 27 的 Apple 芯片 Mac 上开发和试用，较早系统尚未逐版实测。

从项目的 GitHub Release 下载时，在 Assets 中选扩展名为 .dmg 的文件。Source code 是源码压缩包。

首次打开

  1. 升级前先退出 MouseEasy。打开 DMG，双击其中的 MouseEasy.pkg，安装完成后从「应用程序」打开。原有配置会保留。
  2. 当前安装包采用临时签名，未经 Apple 公证。如果系统提示无法验证开发者，请先核对安装包来源。确认可信后，前往「系统设置 → 隐私与安全性」选择「仍要打开」。macOS 12 的入口是「系统偏好设置 → 安全性与隐私 → 通用」。Apple 打开说明
  3. 按 MouseEasy 的提示打开系统设置并允许它控制鼠标输入。macOS 27 的授权项叫「设备控制和数据访问」，较早系统叫「辅助功能」。授权后通过菜单栏的 MouseEasy 图标打开设置。

升级后仍提示授权？如果权限列表里已有 MouseEasy，即使开关已打开，也请先选中旧条目，点列表下方的「−」移除。再把授权浮窗里的新版 MouseEasy 图标拖入列表，打开开关。

要退出，请在「通用 → 启动与显示」点「退出 MouseEasy」。如果两个图标都已隐藏且设置窗口已关闭，在「应用程序」里再次打开正在后台运行的 MouseEasy 即可回到设置。

iPhone 镜像的反转和速度可在「滚动 → iPhone 镜像」中单独设置。镜像另有系统和设备要求。Apple 的 iPhone 镜像要求

简体中文

Download MouseEasy

For Apple silicon Macs with an M1 or later M-series chip, including MacBook, iMac, Mac mini, Mac Studio, and Mac Pro models. Open About This Mac in the Apple menu to check your chip and macOS version.

Requires macOS 12 or later. This arm64 build does not run on Intel Macs. Development and hands-on testing took place on Apple silicon running macOS 27. Earlier system versions have not been individually tested.

On GitHub Releases, choose the .dmg file under Assets. The Source code archives are for developers.

Open for the first time

  1. Quit MouseEasy before updating. Open the DMG and double-click MouseEasy.pkg, then launch MouseEasy from Applications. Your settings carry over.
  2. This build uses an ad hoc signature and has not been notarized by Apple. If macOS cannot verify the developer, check where you obtained the file. For a trusted copy, open System Settings → Privacy & Security and choose Open Anyway. On macOS 12, use System Preferences → Security & Privacy → General. Apple’s instructions
  3. Follow the prompt to allow MouseEasy to control mouse input. The permission is called Device Control and Data Access on macOS 27 and Accessibility on earlier versions. Open settings from the MouseEasy menu bar icon.

Asked for permission again after an update? If MouseEasy is already listed, select the old entry and click the minus (−) button below the list, even if its switch is on. Drag the updated MouseEasy icon from the floating guide into the list and turn on its switch.

To quit, open General → Startup & appearance and click Quit MouseEasy. If both icons are hidden and you have closed settings, reopen the running app from Applications to bring settings back.

Set reversal and speed under Scrolling → iPhone Mirroring. Mirroring has additional device and system requirements. Apple’s iPhone Mirroring requirements
