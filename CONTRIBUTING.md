# Contributing to MouseEasy

For setup, build commands, UI previews and local checks, see the [development guide](docs/development.md). Please follow the [code of conduct](CODE_OF_CONDUCT.md).

To report a bug, include the MouseEasy version, macOS version, the steps that trigger it and what you expected to happen. For a feature request, open an issue to discuss the change before submitting a pull request. Link the issue in the pull request and describe how you tested the change.
